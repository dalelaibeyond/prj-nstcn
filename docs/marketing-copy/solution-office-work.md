# Define an AI assistant around an office task

A useful project brief names the task, the information involved and the person who will review the result.

## Map the current work

Describe how the task is completed today. Include the inputs, tools, expected output and situations that need human judgement.

## Identify the information

List the documents and systems relevant to the task. Note who owns the information and which users should have access.

## Set the review points

Decide which outputs need approval and what should happen when information is missing. Bring these requirements into the development discussion.

## Agree how the task will be evaluated

Use representative examples and an expected result to define the proposed evaluation. Features, system access and deployment are confirmed within the project scope.
