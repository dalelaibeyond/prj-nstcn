# Plan an AI companion product for your users

For businesses considering a companion toy, a clear brief starts with who will use it and the interaction you want to create.

## Identify the intended users

Define the age group, usage setting and role of a parent or other supervising adult. Include the destination market and product expectations.

## Describe the interaction

Write a short example of how the user should interact with the product. Explain what a suitable response looks like and how an unsuitable response should be handled.

## Define content and memory requirements

List the topics, memory settings and controls you want to discuss. Agree how these requirements will be reviewed before the product is used.

## Prepare the product scope

Bring together your product design, brand requirements and evaluation criteria. Specific features and development conditions need to be confirmed.
