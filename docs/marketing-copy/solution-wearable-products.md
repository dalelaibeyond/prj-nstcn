# Plan an AI wearable around its intended use

For an AI glasses project, start with the users, setting and tasks. Product functions and specifications need to be confirmed for the model you are considering.

## Describe the usage setting

Explain when and where the glasses would be used. Include the expected duration of use and the design requirements that matter to your users.

## Define interaction and functions

List the tasks you want the product to support and how users should interact with it. Separate essential requirements from features you would like to explore.

## Discuss data requirements

If a requested feature involves personal information, describe the expected handling, user controls and permissions. The actual approach needs to be confirmed in the product scope.

## Prepare your market brief

Include the target market, branding and documentation requirements. Agree the product scope and evaluation before planning supply.
